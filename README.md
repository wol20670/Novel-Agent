# Novel-Agent

오프라인에서 동작하는 **Ren'Py 비주얼노벨 제작 보조 웹앱** (Vite + React + TypeScript).
엑셀/텍스트로 스토리를 입력하면 → 장면을 자동 분석 → 캐릭터·표정·위치 결정 → 배경·BGM·스프라이트
에셋 생성(AI 또는 폴백) → 인앱 미리보기로 검수/승인 → **배포 가능한 Ren'Py 프로젝트**로 내보낸다.

## 작업 흐름

```
1. 스토리 입력  → 2. 장면·캐릭터 분석 → 3. 에셋 생성     → 4. 미리보기·승인 → 5. ZIP/폴더 출력 → 6. 배포 빌드
   (엑셀/텍스트)    (표정·위치 자동)     (AI 배경·BGM·입화)   (인앱 플레이어)     (Ren'Py 프로젝트)   (실행 파일)
```

- **AI 키 없이도 완전 동작**: 배경/스프라이트는 Canvas 임시 이미지, BGM 은 Web Audio 합성기로 오프라인 생성.
- **OpenAI 키 입력 시**: `gpt-image-1` 으로 실제 배경·CG·캐릭터 입화 생성. 키는 브라우저(localStorage)에만 저장.
- **자체 제작 풀 GUI**: 메인/게임 메뉴·저장/불러오기·설정·기록·도움말·정보·**크레딧** 등 전 화면 직접 정의(외부 GUI 이미지 의존 0). 장르 프리셋 5종 + AI 테마 생성.
- **직접 업로드**: 외부 AI(미드저니/DALL·E 등) 이미지를 배경·스프라이트·CG·메뉴 배경 슬롯에 그대로 업로드(키 불필요).

## 실행

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # 타입체크 + 프로덕션 빌드 (dist/)
npm run typecheck  # tsc --noEmit
```

> ⚠️ `vite dev` 개발 서버에는 알려진 취약점(GHSA-67mh-4wv8-2f99 등)이 있어 **공용/신뢰할 수 없는 네트워크에서 노출 금지**.
> 배포하는 프로덕션 빌드(`dist/`)에는 영향 없음.

## 캐릭터 · 표정 · 배치

### 표정 (감정) — 자동 추론 + 수동 선택 + 미리보기
- 대사에 표정을 안 적어도 **문맥(키워드·문장부호·배경)으로 표정을 자동 추론**한다(`src/generators/emotion/`, 오프라인·결정적). 표정 6종: 기본·기쁨·슬픔·화남·놀람·수줍음.
- 화자 뒤에 `(표정)` 을 명시하면 그 값이 우선(`주인공(기쁨): 안녕!`).
- **장면 카드에서 대사 줄마다 표정을 수동 선택** 가능(자동 추론 위에 덮어쓰기). 직접 지정한 줄은 강조 표시된다.
- 우측 **미리보기 패널의 인앱 플레이어**로 ▶ 대사를 넘기며 **캐릭터·표정·위치를 Ren'Py 내보내기 전에 확인**한다(스프라이트 없으면 임시 이미지로 표시). 표정은 Ren'Py 처럼 다음 변경 전까지 유지된다.

### 주인공(내레이션 전용) 화자
- `주인공`·`나`·`플레이어` 는 **내레이션 전용**으로 자동 분류 — 화면에 스프라이트를 세우지 않고, 에셋 탭 캐릭터 목록·위치 계산·표정 라벨에서 제외된다(대사 이름표·분기에는 정상 참여). 비주얼노벨 1인칭 주인공 관례를 반영.
- 에셋 탭에서 일반 캐릭터를 "내레이션 전용으로" 전환하거나 되돌릴 수 있다.

### 화면 배치
- 한 장면에 서는 캐릭터(주인공 제외)는 **첫 등장 순서로 가로 위치 자동 배정**: 1명=가운데(50), 2명=좌우 대칭(30·70), 3명+=균등 분배.
- 크기는 어떤 해상도 이미지든 `transform vn_char` 가 화면 높이 90%로 `fit` 정규화(머리 잘림 방지).

### 합동 대사 (둘 이상이 동시에)
- `한지수, 강민주: 짠!` 처럼 화자를 `, & / · 、 ＆` 로 묶으면 **합동 대사**가 된다. 멤버 전원의 스프라이트가 함께 서고, 이름표는 묶음 라벨(`한지수 & 강민주`)로 표시된다(`cj_N` 합동 Character).

## AI 설정 (API 실연동 준비)

모든 외부 AI/API 설정은 **`src/config/aiConfig.ts` 한 파일**에 모여 있다. **실연동 시 이 파일 값만 바꾸면** 전체에 반영된다.

- `image`: 이미지 모델(`gpt-image-1`)·품질·엔드포인트(생성/편집)·배경 사이즈 비율·스프라이트 설정.
- `chat`: 테마/표정 모델(`gpt-4o-mini`)·엔드포인트·temperature.
- **API 키는 이 파일/깃에 두지 않는다** — 화면에서 입력 → localStorage 에만 저장. 키 없으면 Canvas/합성 오프라인 폴백.

### 캐릭터 일관성 (GPT 이미지)
- 캐릭터마다 **외형 설명(appearance)** 을 입력하면 6종 표정 프롬프트에 공통 주입된다.
- `consistency: 'reference'`(기본): **'기본' 표정을 먼저 생성 → 그 이미지를 기준으로 나머지 표정을 `images/edits` 로 편집**해 동일 인물을 유지한다. 키 없으면 기존 Canvas 폴백.

## 기기 간 작업 이동 (내보내기 / 가져오기)

작업물(장면·에셋)은 브라우저 로컬 데이터(localStorage + IndexedDB)라 기기마다 분리된다.
왼쪽 패널 **📤 내보내기**로 단일 파일(`<제목>.npproj.zip`)을 저장하고, 다른 기기에서 **📥 가져오기**.

- `.npproj.zip` 안에 `project.json`(장면·캐릭터·설정·에셋 메타) + `assets/`(PNG·WAV) 가 모두 담겨 **AI 생성물까지 그대로 복원**(재생성 불필요).
- OpenAI API 키는 보안상 파일에 **포함되지 않는다**. 새 기기에서 다시 입력.

## Ren'Py 빠른 반복 (폴더 직접 쓰기)

Chrome/Edge 데스크톱에서 **Ren'Py 탭 → "⚡ 폴더에 쓰기"** 로 **프로젝트들의 부모 폴더**(런처 projects 디렉터리)를 한 번 연결하면, 이후 버튼 클릭만으로 생성 파일을 직접 기록한다. 기록 후 게임 창에서 **Shift+R**(리로드)로 즉시 반영.

- 위치: `<연결 폴더>/<프로젝트 제목>/game/...`. 매 동기화마다 `game/` 을 비우고 새로 써서 **낡은 파일이 안 남는다**.
- 폴더 핸들은 IndexedDB 에 저장되어 새로고침 후에도 재사용. 미지원 브라우저는 ZIP 다운로드 사용.

## GUI 테마 (장르 프리셋 · AI 테마 스튜디오)

내보내는 프로젝트는 **자체 제작 풀 GUI**를 포함. 메뉴 배경 외 인터페이스는 전부 코드(Solid) 기반이라 외부 GUI 이미지 의존이 없고, 메뉴 배경만 테마색으로 Canvas 생성된다.

- **장르 프리셋 5종**: 로맨스·공포·SF·스릴러·일상. 좌측 **프로젝트 설정 → GUI 테마**에서 선택.
- **AI 테마 스튜디오**: 분위기/요청 입력 → **✨ AI 테마 생성**. AI 는 **테마 데이터(JSON)만** 출력하고 결정적 컴파일러가 유효한 `gui.rpy`/`screens.rpy` 로 변환(명암대비 강제 보정으로 가독성 보장). 키 없이도 시드 기반 변형 동작.

## 에셋 · UI 업로드 (외부 제작 이미지)

외부 생성형 AI 이미지를 각 슬롯에 그대로 업로드 가능(키 불필요, 키 생성 방식과 공존).

- **배경**: 미리보기 패널 / 에셋 탭 배경 행의 **↥ 업로드**
- **캐릭터 스프라이트**: 에셋 탭 표정 썸네일 호버 시 **↥**(표정별 개별)
- **CG**: 에셋 탭 **🎬 CG 컷** 섹션
- **메뉴 배경**: 좌측 **AI 테마 스튜디오 → 메뉴 배경 직접 업로드**

업로드 에셋은 IndexedDB 에 저장되어 ZIP·폴더쓰기·`.npproj.zip` 에 모두 포함.

## 입력 포맷

### 텍스트 (왼쪽 패널 직접 입력)
```
장면: 맑은 아침, 운동장
배경: 학교 운동장
BGM: morning_breeze
연출: 햇살이 환하게 비추는 아침

주인공(기쁨): 야, 오늘 날씨 진짜 좋다!
(잠시 두 사람은 말없이 서 있었다.)
선택지:
> 앞자리에 앉는다.
> 창가 자리에 앉는다. -> 다른 장면 제목
```

### 엑셀 (.xlsx)
A열 = 화자 이름, B열 = 대사 · 지문 · 태그.
- A열 있음 → 대사 / A열 없고 일반 문장 → 지문(나레이션) / A열 없고 `#`·`>` 시작 → 태그·선택지

| 태그 | 의미 |
|---|---|
| `#S 제목` | 새 장면 시작 |
| `#배경 이름` | 배경 직접 지정 (한 장면에서 바뀌면 자동 분할) |
| `#BGM 파일명` | BGM 지정 |
| `#연출 내용` | 연출 노트 (AI 프롬프트 반영) |
| `#CG 설명` | CG 컷 |
| `#점프 장면제목` | 해당 장면으로 점프 |
| `#끝` | 분기 엔딩(다음 라벨로 새지 않고 종료) |
| `> 텍스트 -> 대상장면` | 선택지 (대상 생략 시 다음으로 진행) |

- `#배경/#BGM/#연출/#CG` 는 바로 위 `#S` 장면에 적용. 한 장면 안에서 **배경이 바뀌면 자동으로 장면이 분할**된다(중간 빈 줄은 무시).
- **표정**: `주인공(기쁨): 안녕!` / **합동 대사**: `한지수, 강민주: 짠!`

## 배포 (실행 파일 만들기 + 개발 파일 제외)

내보낸 Ren'Py 프로젝트는 런처 **"Build Distributions"** 로 Windows/Mac/Linux/Web 독립 실행본을 만든다.

- 생성되는 `game/options.rpy` 에 **개발용 파일 제외 규칙(`build.classify`)** 이 들어 있어, 빌드 시
  원본 아트(psd/psb/ai/xcf/kra/clip)·기획서(docx/xlsx/pptx/hwp)·`dev/`·`docs/`·`기획/` 폴더·편집기 임시/백업/숨김 파일이 **배포판에서 자동 제외**된다.
- 개발용 파일은 프로젝트 안 `dev/` 폴더에 모아두면 한 번에 걸러진다.
- `game/credits.rpy` + 자체 GUI 의 **크레딧 화면**으로 에셋 출처·라이선스를 게임 안에 표기(엔진·나눔고딕 라이선스는 자동). 좌측 **프로젝트 설정 → 크레딧/라이선스 고지** 에 입력.

### 상업/배포 전 체크리스트
- [ ] 임시 배경/합성 BGM/Canvas 메뉴 배경 → **정식 일러스트·BGM·SFX 로 교체**

## 보안 / 라이선스 메모

- **100% 클라이언트 사이드**(백엔드 0). BYO 키 모델 — 키는 localStorage 에만 있고 `api.openai.com` 으로만 HTTPS 전송. 생성 프로젝트·`.npproj.zip` 에 **키가 들어가지 않는다**. XSS 싱크 없음(React 자동 이스케이프, `dangerouslySetInnerHTML`/`eval` 미사용).
- **xlsx(SheetJS)** 는 npm 0.18.5(Prototype Pollution·ReDoS) 대신 **SheetJS 공식 CDN 패치판(0.20.3)** 사용.
- 의존성 라이선스: React/zustand MIT, xlsx Apache-2.0, jszip MIT(듀얼) — 모두 상업적 사용 가능.
- ⚠️ 향후 **당신의 키를 제공하는 호스팅 모델**로 바꾸면 키를 절대 클라이언트에 두지 말 것(백엔드 프록시 필요).

## 아키텍처

| 영역 | 모듈 |
|---|---|
| 파싱 | `src/parser/` — 텍스트/엑셀 → 공통 `Scene[]` (`sceneBuilder` 공유, 자동 분할·합동 화자·주인공 플래그) |
| 표정 | `src/generators/emotion/` — 대사→표정 추론(오프라인 휴리스틱, LLM seam) |
| 이미지 | `src/generators/image/` — 어댑터(OpenAI/Canvas) + 스프라이트 일관성(reference-edit) + 메뉴 아트 |
| 오디오 | `src/generators/audio/` — Web Audio 무드 합성 → WAV |
| GUI 테마 | `src/renpy/gui/` — `GuiTheme` → `gui.rpy`/`screens.rpy` 컴파일러(프리셋 5종, zero-PNG, 크레딧 화면) |
| AI 테마 | `src/generators/theme/` — 색·대비(WCAG)·빌더·OpenAI JSON·오케스트레이터 |
| AI 설정 | `src/config/aiConfig.ts` — 모델·사이즈·품질·엔드포인트 단일 소스 |
| Ren'Py | `src/renpy/generate.ts` — 승인 장면 → `.rpy` 집합(label/menu/jump·표정·위치·build.classify·credits) |
| ZIP | `src/zip/buildZip.ts` — JSZip, 미생성 에셋 폴백 자동 채움(업로드본 우선) |
| 저장 | `src/storage/` — 메타=localStorage, 바이너리=IndexedDB |
| 이동/폴더 | `src/project/transfer.ts`(`.npproj.zip`) · `folderSync.ts`(폴더 직접 쓰기) |
| 상태 | `src/store.ts` — zustand |

> AI 호출은 어댑터로 추상화 — 추후 **백엔드 프록시(SaaS 과금)** 나 다른 provider 로 교체해도 UI·파싱·ZIP 로직 불변.
