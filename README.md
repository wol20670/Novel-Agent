# Novel-Agent

오프라인에서 동작하는 **Ren'Py 비주얼노벨 제작 보조 웹앱** (Vite + React + TypeScript).
엑셀/텍스트로 스토리를 입력하면 → 장면을 자동 분석 → 캐릭터·표정·위치 결정 → 배경·BGM·스프라이트
에셋 생성(AI 또는 폴백) → 인앱 미리보기로 검수/승인 → **배포 가능한 Ren'Py 프로젝트**로 내보낸다.

## 작업 흐름

```
1. 스토리 입력  → 2. 장면·캐릭터 분석 → 3. 에셋 생성     → 4. 미리보기·승인 → 5. ZIP/폴더 출력 → 6. 배포 빌드
   (엑셀/텍스트)    (표정·위치 자동)     (AI 배경·BGM·입화)   (인앱 플레이어)     (Ren'Py 프로젝트)   (실행 파일)
```

- **AI 키 없이도 완전 동작**: 배경/스프라이트는 Canvas 임시 이미지, BGM 은 Web Audio 합성기로 오프라인 생성.
- **NovelAI 키 입력 시**: `NovelAI Diffusion V4.5` 로 실제 배경·CG·캐릭터 입화 생성(서브컬쳐/애니 일러스트 고품질). 키는 브라우저(localStorage)에만 저장. OpenAI `gpt-image-1` 경로도 코드에 남아 있어 `aiConfig.provider` 로 전환 가능.
- **자체 제작 풀 GUI**: 메인/게임 메뉴·저장/불러오기·설정·기록·도움말·정보·**크레딧** 등 전 화면 직접 정의(외부 GUI 이미지 의존 0). 장르 프리셋 5종 + AI 테마 생성.
- **표정·의상 편집**: 표정 세트를 추가·이름변경·삭제하고, 캐릭터마다 의상을 만들어 **대본 `#복장` 태그로 장면별 의상**을 입힌다(의상마다 표정 세트 별도).
- **직접 업로드**: 외부 AI 이미지를 배경·스프라이트·CG·메뉴 배경 슬롯에 그대로 업로드(키 불필요).

## 실행

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # 타입체크 + 프로덕션 빌드 (dist/)
npm run typecheck  # tsc --noEmit
```

> ⚠️ `vite dev` 개발 서버에는 알려진 취약점(GHSA-67mh-4wv8-2f99 등)이 있어 **공용/신뢰할 수 없는 네트워크에서 노출 금지**.
> 배포하는 프로덕션 빌드(`dist/`)에는 영향 없음.

> 🔑 **NovelAI 사용 시 `npm run dev` 로 실행**해야 한다. NovelAI 는 브라우저 직접 호출(CORS)을 막을 수 있어,
> 개발 서버의 `/nai` 프록시(`vite.config.ts`)로 우회한다. NovelAI 계정의 **persistent token(`pst-…`)** 을 좌측 키 칸에 입력.
> 정적 호스팅(`dist/`)으로 배포해 NovelAI 를 쓰려면 별도의 작은 프록시(Node/Tauri 등)가 필요하다. (OpenAI 경로는 프록시 불필요.)

## 캐릭터 · 표정 · 배치

### 표정 (감정) — 편집 가능 + 자동 추론 + 수동 선택 + 미리보기
- 대사에 표정을 안 적어도 **문맥(키워드·문장부호·배경)으로 표정을 자동 추론**한다(`src/generators/emotion/`, 오프라인·결정적). 기본 표정 6종: 기본·기쁨·슬픔·화남·놀람·수줍음.
- **표정 세트 편집**: 에셋 탭 `😀 표정 세트` 에서 표정을 **추가**(예: 당황·황당·윙크)하거나 **이름변경**(화남→황당)·**삭제**할 수 있다(전 캐릭터 공통). `'기본'` 은 스프라이트 기준 입화라 고정. 이름을 바꾸면 이미 만든 캐릭터 입화·대사 표정도 자동으로 이전된다.
- 화자 뒤에 `(표정)` 을 명시하면 그 값이 우선(`주인공(기쁨): 안녕!`). 커스텀 표정 이름도 그대로 인식한다.
- **장면 카드에서 대사 줄마다 표정을 수동 선택** 가능(자동 추론 위에 덮어쓰기). 직접 지정한 줄은 강조 표시된다.
- 우측 **미리보기 패널의 인앱 플레이어**로 ▶ 대사를 넘기며 **캐릭터·표정·의상·위치를 Ren'Py 내보내기 전에 확인**한다(스프라이트 없으면 임시 이미지로 표시). 표정은 Ren'Py 처럼 다음 변경 전까지 유지된다.

### 의상 (복장) — 캐릭터별 의상 + 장면별 `#복장`
- 캐릭터마다 **의상**을 추가할 수 있다(에셋 탭 캐릭터 카드의 `👗 의상` 탭). 각 의상은 **복장 묘사**(예: 흰 비키니 수영복)와 **표정 세트를 따로** 가진다. `'기본'` 의상이 기본값.
- 대본에서 **`#복장 캐릭터:의상`** 으로 그 장면의 의상을 지정한다(여러 명은 쉼표). 명시 전까지 의상은 이어진다.
  ```
  #S 바닷가
  #배경 해변
  #복장 한지수:수영복
  한지수(기쁨): 바다다!
  ```
- 생성은 **기본 외형 + 의상 묘사**를 결합하고, NovelAI 는 이름 기반 시드로 **같은 인물·다른 옷**을 유지한다. 그 장면 의상에 해당 표정 스프라이트가 없으면 **기본 의상으로 자동 폴백**.

### 주인공(내레이션 전용) 화자
- `주인공`·`나`·`플레이어` 는 **내레이션 전용**으로 자동 분류 — 화면에 스프라이트를 세우지 않고, 에셋 탭 캐릭터 목록·위치 계산·표정 라벨에서 제외된다(대사 이름표·분기에는 정상 참여). 비주얼노벨 1인칭 주인공 관례를 반영.
- 에셋 탭에서 일반 캐릭터를 "내레이션 전용으로" 전환하거나 되돌릴 수 있다.

### 화면 배치
- 한 장면에 서는 캐릭터(주인공 제외)는 **첫 등장 순서로 가로 위치 자동 배정**: 1명=가운데(50), 2명=좌우 대칭(30·70), 3명+=균등 분배.
- 크기는 어떤 해상도 이미지든 `transform vn_char` 가 화면 높이 90%로 `fit` 정규화(머리 잘림 방지).

### 합동 대사 (둘 이상이 동시에)
- `한지수, 강민주: 짠!` 처럼 화자를 `, & / · 、 ＆` 로 묶으면 **합동 대사**가 된다. 멤버 전원의 스프라이트가 함께 서고, 이름표는 묶음 라벨(`한지수 & 강민주`)로 표시된다(`cj_N` 합동 Character).

## AI 설정 (API 실연동 준비)

모든 외부 AI/API 설정은 **`src/config/aiConfig.ts` 한 파일**에 모여 있다. **실연동 시 이 파일 값만 바꾸면** 전체에 반영된다.

- `provider`: 활성 이미지 provider — **`'novelai'`(기본)** 또는 `'openai'`. NovelAI 가 검증되면 추후 OpenAI 경로를 제거할 수 있다.
- `image.novelai`: NovelAI 호스트·경로(생성/Director Tools)·모델(`nai-diffusion-4-5-curated`, 서브컬처 미소녀 화풍 최적화)·샘플러·scale(6)·생성 모드(무료/고품질)·**네거티브 프롬프트**·품질 프리픽스·vibe(그림체 참조) 강도.
- `image`(OpenAI): 모델(`gpt-image-1`)·품질·엔드포인트(생성/편집)·사이즈 비율·스프라이트 설정.
- `chat`: 텍스트 모델(`gpt-4o-mini`)·엔드포인트·temperature — **프롬프트 태그 변환** + AI 테마용.

### 프롬프트 태그 컴파일러 (선택 · OpenAI 키)
NovelAI(특히 curated)는 **단부루(Danbooru) 영문 태그** 프롬프트에서 가장 잘 나온다. 좌측에 **OpenAI 키**를 함께 넣으면,
한국어로 적은 외형/배경/CG 설명을 `gpt-4o-mini` 가 규칙대로 영문 태그로 자동 변환한다(`src/generators/image/promptCompiler.ts`):
- 모든 긍정 프롬프트 앞에 품질 프리픽스 `masterpiece, best quality, amazing quality, light novel illustration` 자동 탑재.
- 자연어 → 단부루 태그(예: `은발에 교복을 입은 소녀` → `1girl, solo, silver hair, school uniform`). 구형 만화풍 유도어(anime/manga 등) 제거.
- 감정 → 가중치 태그(`기쁨` → `(smiling:1.3), (happy:1.2)` …). 기본 표정은 LLM 없이 매핑, 커스텀 표정만 번역.
- 스프라이트엔 `transparent background, white background, simple background`, 배경엔 `scenery, no humans` 자동 부착.
- **외형 태그는 캐릭터당 1회만 번역·캐시**해 6표정이 같은 태그를 공유(일관성). 비용 ≈ 장당 $0.0002 (사실상 무시 가능).
- **입력 언어 토글**(좌측 `🇰🇷 한국어 → 영문 변환` / `🔤 영어 태그 그대로`)로 변환 여부를 직접 고른다.
  - **영어 태그 모드**: GPT 호출 없이 입력 태그를 바로 NovelAI 로 전송(OpenAI 키 불필요). 예: `1girl, solo, silver hair, school uniform`.
  - **한국어 모드**: gpt-4o-mini 가 영문 태그로 변환(OpenAI 키 필요). 키가 없으면 한국어 원문을 그대로 전달(차선).
  - 품질 프리픽스·감정·구조 태그는 어느 모드든 동일하게 부착된다. (OpenAI 키는 영어 모드여도 **AI 테마** 생성엔 쓰인다.)
- **API 키는 이 파일/깃에 두지 않는다** — 화면에서 입력 → localStorage 에만 저장. 키 없으면 Canvas/합성 오프라인 폴백.

### NovelAI 동작 방식 (요약)
- 응답은 **ZIP** 으로 오며 첫 PNG 를 추출한다(`jszip`). 호출은 개발 중 `/nai` 프록시 경유(CORS).
- **투명 배경**: NovelAI 는 생성 단계에서 투명배경을 못 만들어, 스프라이트는 불투명 생성 후 **Director Tools `bg-removal`(누끼)** 을 이어 붙여 알파 PNG 를 얻는다.
- **표정 일관성**: OpenAI 의 reference-edit 대신 **이름 기반 고정 시드 + 표정 태그**로 같은 인물·다른 표정을 유지한다.
- **네거티브 프롬프트(핵심 디폴트)**: `lowres, bad anatomy, bad hands, text, error, missing fingers …` 를 항상 적용해 인체 오류를 원천 차단한다.
- GPT 전용 범용 만화풍 유도어(anime/manga)·`NOT photorealistic …` 부정문은 긍정 프롬프트에서 제거했다(화풍은 모델에 맡기고, 피할 것은 네거티브로).

### 설정은 모두 "앱"에서 — 엑셀은 대본만
엑셀(.xlsx)은 **대본 한 가지**만 담는다(A=화자/B=대사·태그). 캐릭터·배경·CG·테마 등 **모든 설정은 앱에서** 프롬프트로 한다. 각 항목엔 **기본 스타일(디폴트)** 이 자동으로 붙으므로, 사용자는 **고유한 디테일만** 짧게 적으면 된다.

**캐릭터 설정(외형·성격)** — 같은 인물을 일관되게 그리는 핵심:
- 에셋 화면 캐릭터 카드의 **외형**(예: 갈색 단발, 교복, 푸른 눈)·**성격·역할** 칸에 적는다. 외형은 모든 표정 프롬프트에 공통 주입되어 **동일 인물 유지**, 성격은 **분위기·표정** 참고로 들어간다. (디폴트로 "서브컬쳐 게임 그림체, 전신 풀샷, 투명 배경 PNG"가 자동 적용 — 외형만 적으면 됨.)
- 재분석/대본 수정 시에도 입력한 외형·성격·내레이션·**의상** 설정은 **보존**된다.
- **🎨 그림체 참조(선택, 여러 장, 전 캐릭터 공통)** — 에셋 캐릭터 섹션 상단에 마음에 드는 일러스트를 **여러 장** 업로드하면, **기본 입화** 생성 시 그 **화풍·채색만** 참고(NovelAI **vibe transfer**)하고 인물은 외형 설명대로 새로 그린다. **장수가 많을수록 화풍 반영이 정확**해진다. 썸네일마다 `×` 로 제거. 프롬프트에 **URL 링크는 무효**(API가 못 봄) — 반드시 이미지 파일을 올린다. 표정들은 기본 입화를 기준으로 그려져 자동으로 같은 화풍을 따른다.

### 캐릭터 일관성 + 비용 절약 워크플로우
- **① 기본 입화 먼저 1장 생성** → 마음에 들면 **표정 썸네일을 하나씩 클릭**해 그 표정만 생성한다.
  - **NovelAI**: 같은 캐릭터는 **이름 기반 고정 시드 + 표정 태그**로 동일 인물·다른 표정을 유지(불투명 생성 → 누끼).
  - **OpenAI**: 저장된 '기본'을 기준(`images/edits`)으로 그려 동일 인물 유지.
  - "전체 생성" 버튼은 표정 세트 일괄 옵션. 의상 탭에서는 그 **의상의** 표정 세트를 생성한다.
- 키 없으면 Canvas 폴백.

### 미세 수정 (refine) — 마음에 드는 결과를 버리지 않고 조금만 손보기
- 배경(미리보기 **✏️ 수정**) · 캐릭터 입화(썸네일 **✏️** = 그 표정만)에서 지시문을 입력하면 **그 이미지를 기준으로 부분만 편집**(예: "노을을 더 붉게", "머리를 더 짧게")한다. 키 필요.
- **🎨 디자인 수정**(캐릭터 카드) — **기본 입화의 디자인**(머리·의상·소품 등)을 지시문대로 바꾸고, **이미 만든 다른 표정도 새 기본을 기준으로 다시 그려** 디자인을 일관되게 맞춘다(예: "머리를 단발로", "안경을 씌워"). 표정 수만큼 재생성하므로 비용이 더 든다.
- 음악은 BGM 행의 무드·템포·볼륨을 바꿔 재생성하면 된다.

### CG 설명은 "위치 표시 + 프롬프트" — 대본엔 짧게, 앱에서 자세히
`#CG`는 **게임에서 CG 가 나오는 위치(타이밍)** 를 정하는 표시이자 **생성 프롬프트** 역할을 겸한다.
대본엔 `#CG n1` 처럼 **짧은 라벨**만 적어 자리를 잡고, 에셋 탭 CG 행의 **설명 칸을 편집**해
그 컷의 자세한 장면(예: "노을 아래 마주보며 손잡는 장면")을 적으면 그게 생성 프롬프트로 쓰인다.
이미 만든 이미지는 설명을 바꿔도 유지된다. (배경 이름 편집과 동일한 방식.)

### 캐릭터 참조 CG (🎭) — 인물을 닮은 CG
CG 컷 행에서 **참조 인물**을 고르고 **🎭** 를 누르면, 텍스트만으로 새로 그리지 않고
**그 캐릭터의 기본 입화를 소스**(NovelAI=img2img / OpenAI=`images/edits`)로 줘서
**인물 정체성을 최대한 유지한 CG** 를 만든다(기본 입화가 있는 캐릭터만 목록에 뜸). 배경은 텍스트 묘사로 반영.
- 일반 **생성**(텍스트만)은 이름만 보고 그려 캐릭터와 안 닮을 수 있으니, 등장인물 CG 는 🎭 를 권장.
- 입화는 정면·단일 인물이라 **큰 포즈·구도 변화**는 한계가 있다(정체성은 잘 유지, 포즈는 근사치). 변화 폭이 작을수록 잘 나오고, 이후 **✏️ 수정**으로 다듬을 수 있다.

### 생성물 자동 보관
AI 로 생성하는 모든 결과가 보관 폴더에 자동 저장된다 — 배경·캐릭터 입화·**CG**·**BGM(.wav)**
(`backgrounds/`·`characters/<이름>/<의상>/`·`cg/`·`music/`, 타임스탬프 파일명).

## 기기 간 작업 이동 (내보내기 / 가져오기)

작업물(장면·에셋)은 브라우저 로컬 데이터(localStorage + IndexedDB)라 기기마다 분리된다.
왼쪽 패널 **📤 내보내기**로 단일 파일(`<제목>.npproj.zip`)을 저장하고, 다른 기기에서 **📥 가져오기**.

- `.npproj.zip` 안에 `project.json`(장면·캐릭터·설정·에셋 메타) + `assets/`(PNG·WAV) 가 모두 담겨 **AI 생성물까지 그대로 복원**(재생성 불필요).
- API 키(NovelAI/OpenAI)는 보안상 파일에 **포함되지 않는다**. 새 기기에서 다시 입력.

## Ren'Py 빠른 반복 (폴더 직접 쓰기)

Chrome/Edge 데스크톱에서 **Ren'Py 탭 → "⚡ 폴더에 쓰기"** 로 **프로젝트들의 부모 폴더**(런처 projects 디렉터리)를 한 번 연결하면, 이후 버튼 클릭만으로 생성 파일을 직접 기록한다. 기록 후 게임 창에서 **Shift+R**(리로드)로 즉시 반영.

- 위치: `<연결 폴더>/<프로젝트 제목>/game/...`. 매 동기화마다 `game/` 을 비우고 새로 써서 **낡은 파일이 안 남는다**.
- 폴더 핸들은 IndexedDB 에 저장되어 새로고침 후에도 재사용. 미지원 브라우저는 ZIP 다운로드 사용.

## GUI 테마 (장르 프리셋 · AI 테마 스튜디오)

내보내는 프로젝트는 **자체 제작 풀 GUI**를 포함. 메뉴 배경 외 인터페이스는 전부 코드(Solid) 기반이라 외부 GUI 이미지 의존이 없고, 메뉴 배경만 테마색으로 Canvas 생성된다.

- **장르 프리셋 5종**: 로맨스·공포·SF·스릴러·일상. 좌측 **프로젝트 설정 → GUI 테마**에서 선택.
- **AI 테마 스튜디오**: 분위기/요청 입력 → **✨ AI 테마 생성**. AI 는 **테마 데이터(JSON)만** 출력하고 결정적 컴파일러가 유효한 `gui.rpy`/`screens.rpy` 로 변환(명암대비 강제 보정으로 가독성 보장). 키 없이도 시드 기반 변형 동작.

## 에셋 · UI 업로드 (외부 제작 이미지)

외부 생성형 AI 이미지를 각 슬롯에 그대로 업로드 가능(키 불필요, 키 생성 방식과 공존).

- **배경**: 미리보기 패널 / 에셋 탭 배경 행의 **↥ 업로드**
- **캐릭터 스프라이트**: 에셋 탭 표정 썸네일 호버 시 **↥**(선택한 의상의 표정별 개별)
- **CG**: 에셋 탭 **🎬 CG 컷** 섹션
- **메뉴 배경**: 좌측 **AI 테마 스튜디오 → 타이틀·메뉴 배경** — **✨ AI 생성**(NovelAI/OpenAI) 또는 **↥ 직접 업로드**. **참조 캐릭터·배경**을 고르면 그 입화·배경을 소스로 **게임과 어울리게 합성**하고(권장), 고르지 않으면 제목·장르·분위기 텍스트로 생성한다(이 경우 **장르·분위기를 먼저** 정하고 생성). 둘 다 `game/gui/main_menu.png`·`game_menu.png` 슬롯을 채우며, 없으면 Canvas 절차 생성으로 폴백.

업로드 에셋은 IndexedDB 에 저장되어 ZIP·폴더쓰기·`.npproj.zip` 에 모두 포함.

### 생성 이미지 자동 보관 (폴더)
좌측 **📁 이미지 보관 폴더**를 한 번 연결하면, **AI 로 생성한 배경·캐릭터 입화·CG·메뉴·BGM**이 생성될 때마다 그 폴더에
자동 저장된다(`backgrounds/`, `characters/<이름>/`, `cg/`, `menu/`, `music/` 분류 + 타임스탬프 파일명). **재생성해도 이전 이미지가
폴더에 그대로 남아** 비용 들인 결과를 잃지 않고 나중에 다시 고를 수 있다(Chrome/Edge, 폴더 핸들은 IndexedDB 유지).
- **권한 주의**: 브라우저 보안상 **페이지를 새로고침하면 폴더 쓰기 권한이 풀려** 저장이 조용히 실패할 수 있다.
  이때 보관 폴더 표시가 **주황색**으로 바뀌며 **"⚠️ 폴더 권한 허용"** 버튼이 뜬다 — 한 번 눌러 재허용하면 다시 저장된다(초록색).
- Canvas 임시 이미지(키 없이 생성)는 보관 대상이 아니다(비용이 든 AI 결과만 저장).

### 배경: 이름은 라벨, 프롬프트는 따로 — 그리고 기준 배경 일관성
- 배경 **이름**(이른 아침의 카페 등)은 **공유 라벨**로만 쓰고, 그 아래 **상세 프롬프트 칸**에 자세히 적으면 그 텍스트로 생성한다(이름은 그대로 유지). 비우면 이름을 프롬프트로 사용.
- **🪄 기준으로 생성**: 이미 만든 다른 배경을 **기준(소스)** 으로 골라 생성하면, **같은 장소·구도·화풍을 유지**하며 시간대·조명만 바꿔 일관성을 확보한다(예: '이른 아침 카페' → '밤 카페').
- 배경 그림체는 캐릭터(`artStyle`)와 분리된 `backgroundStyle`(더 디테일·사실적 조명, 덜 평면적)을 쓴다.

### 생성 모드 · 비용 (전역 선택)
좌측 **NovelAI 이미지 API** 아래 **생성 모드**(무료/고품질)가 **모든 생성**(배경·캐릭터·CG·메뉴)에 적용된다.

**NovelAI(기본)** — 비용은 품질 슬라이더가 아니라 **모드(해상도)** 로 정해진다:

| 모드 | 해상도 | 비용 |
|---|---|---|
| **무료** | ≤1MP (832×1216 · 1216×832 · 1024×1024), 28스텝 | **Opus 구독 무제한 무료** |
| **고품질** | Large (1024×1536 · 1536×1024 · 1472×1472), 28스텝 | 장당 **Anlas** 소모(더 선명·디테일) |

- **무료**로 구성·일관성을 확인하고, 마음에 드는 최종본만 **고품질**로 재생성하면 Anlas 를 아낀다.
- **스프라이트 누끼**(Director Tools `bg-removal`)는 Director 도구라 **소량 Anlas** 가 들 수 있다.
- 품질의 핵심은 모드보다 **모델(V4.5) + 프롬프트 + 네거티브**다.

**OpenAI(`gpt-image-1`, provider 전환 시)** — 품질이 곧 단가:

| 품질 | 캐릭터(1024×1536) | 배경/CG(1536×1024) | 용도 |
|---|---|---|---|
| **초안** low | ~$0.016 | ~$0.016 | 구도·일관성 확인 |
| **표준** medium | ~$0.06 | ~$0.06 | 일반 |
| **고품질** high | ~$0.25 | ~$0.25 | 최종본 |

권장: **초안으로 전체 구성 확인 → 마음에 드는 것만 고품질로 재생성**.

> **해상도 참고**: 프로젝트 캔버스는 **1920×1080(16:9)** 지만, 실제 출력 픽셀은 모델 격자에 맞춰진다 — NovelAI 는 **832×1216**(세로/스프라이트)·**1216×832**(가로/배경·CG)·**1024×1024**, gpt-image-1 은 **1024×1536**·**1536×1024**. Ren'Py 가 1920×1080 화면에 맞춰 스케일하므로 결과는 16:9 로 보인다(정확히 1920×1080 출력은 불가).

### 인게임 GUI — 대사창·폰트 (좌측 AI 테마 스튜디오)
- **창 색·불투명도**: 대사창/선택지 배경색(기본 검정)과 불투명도(권장 10~20%) 조절 — 스크린샷처럼 반투명 검정 박스.
- **본문색/이름색**: 본문 글자색(예: 흰색)·화자 이름색(예: 포인트 컬러) 지정.
- **글자 외곽선**: 켜면 본문·이름에 외곽선(기본 검정, 색 지정 가능) — 밝은 배경 위 가독성↑.
- 값은 테마 위에 덮어써 빌드/내보내기에 반영된다("기본값"으로 초기화 가능).

## 입력 포맷

### 텍스트 (왼쪽 패널 직접 입력)
```
장면: 맑은 아침, 운동장
배경: 학교 운동장
BGM: morning_breeze
연출: 햇살이 환하게 비추는 아침

주인공(기쁨): 야, 오늘 날씨 진짜 좋다!
(잠시 두 사람은 말없이 서 있었다.)
선택지:
> 앞자리에 앉는다.
> 창가 자리에 앉는다. -> 다른 장면 제목
```

### 엑셀 (.xlsx)
A열 = 화자 이름, B열 = 대사 · 지문 · 태그.
- A열 있음 → 대사 / A열 없고 일반 문장 → 지문(나레이션) / A열 없고 `#`·`>` 시작 → 태그·선택지

| 태그 | 의미 |
|---|---|
| `#S 제목` | 새 장면 시작 |
| `#배경 이름` | 배경 직접 지정 (한 장면에서 바뀌면 자동 분할) |
| `#BGM 파일명` | BGM 지정 |
| `#복장 캐릭터:의상` | 이 장면의 캐릭터 의상 (여러 명은 쉼표: `한지수:수영복, 강민주:교복`) |
| `#연출 내용` | 연출 노트 (AI 프롬프트 반영) |
| `#CG 설명` | CG 컷 |
| `#점프 장면제목` | 해당 장면으로 점프 |
| `#끝` | 분기 엔딩(다음 라벨로 새지 않고 종료) |
| `> 텍스트 -> 대상장면` | 선택지 (대상 생략 시 다음으로 진행) |

- `#배경/#BGM/#복장/#연출/#CG` 는 바로 위 `#S` 장면에 적용. 한 장면 안에서 **배경이 바뀌면 자동으로 장면이 분할**된다(중간 빈 줄은 무시). 의상은 명시 전까지 이어진다.
- **표정**: `주인공(기쁨): 안녕!` (커스텀 표정 이름도 인식) / **합동 대사**: `한지수, 강민주: 짠!`
- **표정·의상은 앱 [에셋] 탭에서 추가·이름변경**할 수 있다(엑셀엔 대본만, 설정은 앱에서).

## 보안 / 라이선스 메모

- **100% 클라이언트 사이드**(백엔드 0). BYO 키 모델 — 키는 localStorage 에만 있고 이미지 provider 호스트(`image.novelai.net` 또는 `api.openai.com`)로만 HTTPS 전송. 생성 프로젝트·`.npproj.zip` 에 **키가 들어가지 않는다**. XSS 싱크 없음(React 자동 이스케이프, `dangerouslySetInnerHTML`/`eval` 미사용).
- **NovelAI 는 개발 서버의 `/nai` 프록시 경유**(CORS). 정적 배포로 NovelAI 를 쓰려면 별도 프록시가 필요(키는 여전히 클라이언트에만 — 공개 호스팅 시 프록시가 키를 대신 들고 있지 않도록 설계 주의).
- **xlsx(SheetJS)** 는 npm 0.18.5(Prototype Pollution·ReDoS) 대신 **SheetJS 공식 CDN 패치판(0.20.3)** 사용.
- 의존성 라이선스: React/zustand MIT, xlsx Apache-2.0, jszip MIT(듀얼) — 모두 상업적 사용 가능.
- ⚠️ 향후 **당신의 키를 제공하는 호스팅 모델**로 바꾸면 키를 절대 클라이언트에 두지 말 것(백엔드 프록시 필요).

| 표정 | `src/generators/emotion/` — 대사→표정 추론(오프라인 휴리스틱, LLM seam). 표정 세트는 `project.expressions` 로 편집 |
| 이미지 | `src/generators/image/` — provider 어댑터(**NovelAI**/OpenAI/Canvas) + 스프라이트 일관성(시드/reference-edit) + 다중 vibe + bg-removal 누끼 + 메뉴 아트 |
| 오디오 | `src/generators/audio/` — Web Audio 무드 합성 → WAV |
| GUI 테마 | `src/renpy/gui/` — `GuiTheme` → `gui.rpy`/`screens.rpy` 컴파일러(프리셋 5종, zero-PNG, 크레딧 화면) |
| AI 테마 | `src/generators/theme/` — 색·대비(WCAG)·빌더·OpenAI JSON·오케스트레이터 |
| AI 설정 | `src/config/aiConfig.ts` — provider 스위치·모델·사이즈·품질·네거티브·vibe·엔드포인트 단일 소스 |
| Ren'Py | `src/renpy/generate.ts` — 승인 장면 → `.rpy` 집합(label/menu/jump·표정·**의상**·위치·build.classify·credits; 속성 `<의상> <표정>`) |
| ZIP | `src/zip/buildZip.ts` — JSZip, 미생성 에셋 폴백 자동 채움(업로드본 우선) |
| 저장 | `src/storage/` — 메타=localStorage, 바이너리=IndexedDB |
| 이동/폴더 | `src/project/transfer.ts`(`.npproj.zip`) · `folderSync.ts`(폴더 직접 쓰기) |
| 상태 | `src/store.ts` — zustand |

> AI 호출은 provider 어댑터로 추상화 — `aiConfig.provider` 로 **NovelAI ↔ OpenAI** 를 바꾸거나 추후 백엔드 프록시로 교체해도 UI·파싱·ZIP 로직 불변.

npm run typecheck   # 타입 검사
